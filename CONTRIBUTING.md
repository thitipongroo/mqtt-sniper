# Contributing to MQTT Sniper

Thank you for your interest in contributing to **MQTT Sniper**!

## Development Prerequisites

- **Rust Toolchain**: Stable Rust (Edition 2024, Rust `1.85+` recommended)
- **Cargo**: Included with `rustup`
- **Docker** (Optional): For building and testing container images

## Getting Started

1. Fork and clone the repository:

```bash
   git clone https://github.com/thitipongroo/mqtt-sniper.git
   cd mqtt-sniper
```
