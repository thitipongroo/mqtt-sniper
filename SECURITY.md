# Security Policy

## Supported Versions

The following versions of `mqtt-sniper` are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of `mqtt-sniper` seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Use [GitHub Private Vulnerability Reporting](https://github.com/thitipongroo/mqtt-sniper/security/advisories/new) or contact the maintainer directly via the email listed in `Cargo.toml`.
3. Include a clear description of the issue, steps to reproduce, and potential impact.

We aim to acknowledge vulnerability reports within **48 hours** and provide a remediation plan or patch release within **7 days**.
